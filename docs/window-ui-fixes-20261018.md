# RC3 窗口修正与验收

基于 GitHub `1704919/WuziDesktopPet` 的 `main`（`176a2b6`），包含已合并的 B 站开播提醒。
本次修改对应 `v0.1.1-rc3` 候选包，代码与 Release 分开发布。版本说明见 [v0.1.1-rc3](release-notes-v0.1.1-rc3.md)。

## 本次行为变化

- 桌宠和自定义面板隐藏 Windows 任务栏入口，保留键盘焦点和中文输入能力。
- 文件工作台去除系统标题栏，增加自定义关闭按钮、标题拖动区和右下角缩放角；初始大小适应屏幕可用区域。处理确认框保留原确认流程，并去除系统标题栏。
- 聊天、天气、开播提醒和昵称设置使用独立的透明无边框窗口，拖动标题移动。面板按内容自动增高，首次打开及重新打开时限制在屏幕可用区域内。
- 同一次运行中，表单重新打开时保留拖动位置。右键菜单和桌宠说话气泡仍跟随桌宠原有交互。

## 模块归属

| 模块 | 职责 |
| --- | --- |
| `godot/scripts/windows_window_policy.gd` | 异步调用 Windows 窗口样式组件 |
| `tools/native/window_style.h` | 校验 HWND 所属进程，设置工具窗口样式并移除任务栏入口 |
| `godot/scripts/frameless_window.gd` | 通用无边框配置、窗口显示、屏幕边界和缩放角 |
| `godot/scripts/window_drag_handle.gd` | 使用桌面坐标处理拖动与缩放，仅在拖动中逐帧更新 |
| `godot/scripts/popup_card_controller.gd` | 表单内容布局、自动高度、关闭和位置保持 |
| `godot/scripts/batch_file_window.gd` | 文件工作台原有功能及窗口组件接入 |

`main.gd` 仅更新四个窗口变量的类型、移除旧嵌入式面板的鼠标命中区域，没有增加窗口实现代码。原有文件组件复用同一个短时运行的 EXE；窗口样式实现与文件操作分开。

## 交付与手动验收

先退出旧版，完整解压 `WuziDesktopPet-v0.1.1-rc3-win64.zip`（约 91.7 MiB），再运行其中的 `舞梓桌宠.exe`。
请保持 `native` 文件夹与 EXE 同级。

2026-10-18，维护者检查候选版后反馈未发现问题，并确认推送源码。其他环境仍可按以下项目检查：

1. 桌宠启动后，任务栏没有 Godot 图标。
2. 聊天、天气、开播提醒、昵称面板可通过标题拖动；开播提醒底部按钮完整可见。
3. 文件工作台无额外系统标题栏，能拖动标题、使用右下角缩放，并可正常关闭。
4. 重点体验快速拖动、跨屏幕移动和自己的 Windows 缩放比例；这些主观体验及多屏场景尚未宣称验收通过。
