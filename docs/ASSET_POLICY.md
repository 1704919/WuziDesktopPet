## 2. 角色形象与动画

- 舞梓／阿梓相关角色设定、服饰设计、名称、表情和可能的原始创作元素，相关权利归各自合法权利人所有。
- `assets/references/` 中的第三方截图、收藏集和参考图仅用于作者本地研究；**不随公开 Git 仓库及 Release 分发**。
- `分享区/Q版/` 下的母版、原始 MP4、动作提示词和制作资料目前保留于本地；**不默认公开上传**。
- `godot/assets_display/` 下的透明 PNG/OGV 是由角色视频加工而来。技术上是新生成/重新处理，**不等于自动获得角色设计或原视频的公开再分发权利**。本项目实际可运行 ZIP 仅包含这些经过处理的动画和 Godot 程序资源，不包含原始 MP4、母版或第三方参考图。
- 若未来取得许可，需要记录权利方、授权文本/URL、具体允许用途（免费分发、修改、二次传播、商业用途等）、署名方式、期限和撤销条件。只有满足这些条件的素材才可单独归档并考虑上传。
- 2026-10-10：本机已生成带有处理后动画的完整 Windows ZIP，**尚未上传到 GitHub 或其他公开地址**。用户认为此用途属于正常粉丝二创；这属于项目方的判断，而不是已核实的权利人许可或法律结论。公开上传前应依据适用的角色/素材使用规则确认分发条件及限制；发现权利人明确禁止分发时应遵守相应规则。

## 4. 引擎及第三方组件

- Godot 采用 MIT 许可证。分发嵌入 Godot 引擎的 Windows 可执行程序时，应保留适当的 Godot 版权与许可声明；不要只复制本项目自己的 LICENSE 替代上游许可。
- Windows 原生文件桥接组件由项目源码编译，依赖 Windows 系统 API／WIC；HEIC 编解码能力取决于最终用户的系统。这里不附带第三方 HEIC/HEVC 编解码库。
- NumPy、Pillow、imageio-ffmpeg 等属于开发/素材生产依赖；若以后在 Release 中打包它们的可执行组件或二进制，必须按当时实际分发内容核对上游许可和通知要求。

## 6. 推荐的公开方式

公开方案采用双层结构：Git 仓库只含 **MIT 代码及配置**，不跟踪原始视频或参考图；在作者确认相关分发条件的前提下，通过 **GitHub Releases 提供运行资源已嵌入 PCK 的 Windows 便携 ZIP**。ZIP 随附 `ASSET_NOTICES.txt` 与 Godot 上游许可文本。仅下载源码的开发者不会获得完整角色素材，普通用户下载 Release ZIP 可以直接运行。

若未来希望允许第三方替换自己的角色，可考虑**可更换资源的架构与非受限演示素材**。这属于后续功能，不应为了发布强行推倒现有工程。
