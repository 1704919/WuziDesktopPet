 9 | ## 交互

- 左键点击：视频反应和 Q 弹；连续 Q 弹与视频冷却相互独立。
- 按住并移动超过阈值后拖动；松手支持抛掷。
- 右键“对她说”：最多 50 字符的本地短句聊天，支持问候、夸奖、休息、吃饭、摸摸等意图和简单话题承接。
- 右键“设置 → 用户昵称”：最多 12 字符，支持保存、修改、清除，重启保留；首次启动不要求设置。
- 同意图有多条回复，最多保留三轮、120 秒内的话题。对话不联网；字符按 Unicode 码点计数，组合 Emoji 可能占多个字符。
- 拖入文件或右键“文件处理…”打开统一工作台，支持批量重命名、PNG/JPG/WebP/HEIC 转换、目标预览、指定目录输出、进度与取消。确认预览后才处理；不覆盖已有文件，失败项保留。HEIC 使用 Windows 系统组件，界面分别显示读写支持。
- 原目录模式就地重命名，图片转换保留原图；指定目录生成副本，保留原文件。音频和视频只参与普通重命名／复制，不提供转码。聊天提到文件处理仍只给指引。
- 回复气泡为单一圆角卡片，支持换行和分页。
- 右键“点播动作”按点击、一般、休息与睡眠分类。29/92 双向彩蛋、情绪动作联动与无互动自动睡眠已接入。
- “查看天气”保留在右键首页，天气设置在“设置”子菜单内。
